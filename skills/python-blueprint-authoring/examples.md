# Examples

- Positive: Draft a greenfield library blueprint that fixes package layout, entrypoints, testing anchor, lint/type/test toolchain, and measurable acceptance signals without pretending to execute the baseline.
- Positive: Reroute a repository with existing packages and conflicting config remnants because it is retrofit-shaped rather than greenfield.
- Negative: Treat a migration request as greenfield just to keep using this skill, or couple the blueprint to executor-specific provenance or copy behavior.
