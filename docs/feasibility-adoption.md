# SSH 下載採用紀錄

## 來源與採用範圍

- 正式基準為合併 [Topic 1 PR #131](https://github.com/a129924/agent-skills/pull/131) 的 `4058339`。E001 記錄當時 Codex 權限拒絕存取既有控制 socket，適用於當時的權限設定。
- 側對話在本機 macOS Codex，以單次唯讀基線、指定 socket、限指定目的地寫入、直接網路關閉的條件下載 63,319 bytes。兩端 SHA-256 一致，本機模式為 `0600`。這份觀察作為可行性證據。
- 候選來源為 `c86f05e`。依 [正式計畫](../plan/ssh-ops/ssh-ops.plan.md) 審查後，採用 [Skill](../skills/ssh-ops/SKILL.md) 及 [範例](../skills/ssh-ops/examples.md) 的單檔契約、同一 master、一次性權限及安全交付。補明啟用版本檢查、目的地 basename、受授權的遠端連結目標、客戶端命令設定及單一 SHA-256 解析。候選的工作樹、規劃、審查狀態與測試腳本留在原處。

## 本機受控驗證

- YAML frontmatter、必要章節、相對連結及兩段 Bash 範例的語法檢查通過。OpenSSH 10.2p1 用空白設定與含代理、遠端命令衝突的 `-F` 測試設定確認有效參數。
- Codex CLI 0.172.0 的受控沙箱允許指定測試 socket 與目的目錄寫入，拒絕對照 socket、目錄外寫入及直接網路。測試使用本機 socket 與暫存目錄。
- 檔案測試替身各自驗證成功與 `0600`、socket 拒絕、目的地不可寫、原子交付碰撞、部分輸出逾時及雜湊不符。碰撞保留既有內容，失敗案例沒有新成品或遺留暫存。OpenSSH 在缺少控制 socket 的離線案例使用本機失敗備援。
- 正式版本尚無 native `$ssh-ops` 載入或實機 SSH 證據。上述本機檢查使用測試資料，無實機矩陣覆蓋。
